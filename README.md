## How to Run
1. Make sure Python 3.10+ is installed (`python --version`).
2. Open a terminal inside the `codes/` folder.
3. Run any exercise file directly, for example:
    python Lab1_DauNgocAnhVu_ITDSIU24059_Ex1.py
4. Exercises that require input (e.g. Ex2, Ex4, Ex5, Ex9, Ex12, Ex13, Ex14, Ex15) will prompt for values in the terminal.
5. Exercises 6, 7, 9 and 11 use `pandas` and/or `matplotlib`. Install them first if needed:
   pip install pandas matplotlib
